Field firmware update for IP intercom nodes

Added firmware update, per-input reporting and codec selection to an existing Windows configuration tool for IP intercom nodes.

  • Integrated the production firmware loader, so one tool updates four device variants on two processor families, node by node, and lists any node that fails.
  • Worked out where new settings fit in an existing UDP protocol, using an unused data word and spare bits, and agreed the layout with the firmware developer.
  • Added file-name checks per device variant as a safety layer, and wrote the illustrated user manual for the update procedure.

Hardware · Root cause · QA

Ethernet failure investigation and production quality

Found the cause of an Ethernet failure affecting more than 300 access control units, then took on testing and release of the product line.

  • Used a working Bluetooth link to confine the fault to the Ethernet path, then compared failing boards against known-good ones, circuit by circuit, to isolate the PHY device.
  • Traced the failures to counterfeit parts of the wrong temperature grade; reworked about 50 units and trained the workshop to complete the rest.
  • Recovered a production test jig that was rejecting good units, by tracing a wiring fault, rewiring it and labelling every wire.
  • Carried out component-level fault-finding and repair on returned intercom and access control boards, with release authority on final checks.
