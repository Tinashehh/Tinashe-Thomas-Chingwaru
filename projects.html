Field firmware update for IP intercom nodes

Added firmware update, per-input reporting and codec selection to an existing Windows configuration tool for IP intercom nodes.

  • Integrated the production firmware loader, so one tool updates four device variants on two processor families, node by node, and lists any node that fails.
  • Worked out where new settings fit in an existing UDP protocol, using an unused data word and spare bits, and agreed the layout with the firmware developer.
  • Added file-name checks per device variant as a safety layer, and wrote the illustrated user manual for the update procedure.
